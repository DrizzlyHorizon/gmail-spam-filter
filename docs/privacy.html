Privacy policy

gmail-spam-filter is a personal program that runs on a device owned by the account holder. It is used only by its owner, on their own Gmail account.

What data it accesses

  • Gmail messages (gmail.modify): to read incoming mail, score it for spam, and apply labels, move messages to spam or trash.
  • Gmail filter settings (gmail.settings.basic): to create filters that block spam senders.
  • Contacts and "Other contacts" (read-only): so mail from people the owner knows is never filtered.

How the data is used and stored

  • All processing happens locally on the owner's device. No email content is sent to any third-party server.
  • Email content is not stored. The program keeps only its position in the mailbox and a cached list of the owner's contact email addresses, on the local device.
  • No data is sold, shared, or used for advertising or any purpose other than filtering spam.

Google API Services User Data Policy

This app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
